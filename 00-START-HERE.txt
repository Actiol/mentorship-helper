   - Click "Deploy the stack"

   curl -k https://mentorship.actiol.dev/health
   curl -k https://mentorship.actiol.dev/docs

================================================================================
                      TROUBLESHOOTING
================================================================================

Service Won't Start:
  1. Check logs: docker logs <service-name>
  2. Verify env vars are set
  3. Check disk space: docker exec <service> df -h
  → See README-PORTAINER.md → Troubleshooting

Database Connection Failed:
  1. Test: docker exec mentorship-db psql -U mentorship
  2. Check POSTGRES_PASSWORD matches in .env
  → See OPERATOR-CHECKLIST.md → Incident Response

SSL Certificate Errors:
  1. Verify files: ls -la nginx/certs/
  2. Check expiration: openssl x509 -in nginx/certs/fullchain.pem -noout -dates
  3. Restart nginx if updated
  → See README-PORTAINER.md → SSL/TLS Setup
