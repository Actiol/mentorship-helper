TROUBLESHOOTING QUICK REFERENCE
================================================================================

Service won't start:
  -> Check logs: docker logs <service-name>
  -> Review environment variables
  -> Verify disk space: docker exec <service> df -h

High error rate:
  -> Check logs: docker logs -f <service>
  -> Verify connectivity between services
  -> Check resource limits (CPU, memory)

SSL certificate errors:
  -> Verify files: ls -la nginx/certs/
  -> Check expiration: openssl x509 -in nginx/certs/fullchain.pem -noout -dates

Database issues:
  -> Test connection: docker exec mentorship-db psql -U mentorship
  -> Check disk space: docker exec mentorship-db df -h
  -> Restore from backup if needed
